# 근거자료집 — 알레르기 유발물질

> **MVP 범위 밖 (2026-09-17 결정).** MVP 는 알레르기·알레르겐을 다루지 않고, 사용자가 고른 기준 원재료의
> 포함 여부만 보여준다. 이 문서와 `allergen_map.csv`·`10_build_allergen_map.py` 는 보관만 하며 갱신하지 않는다.
> 검증에서 나온 알레르겐 규칙 오류(`docs/21` §2-C·§8-1)도 고치지 않았다.

감미료·첨가물과 **근거의 종류가 다르다.** ADI 같은 수치가 아니라
「식품등의 표시기준」이 정한 **법정 표시 의무**가 근거다.
수치가 없으므로 "얼마까지 괜찮다"가 아니라 "들어 있으면 반드시 적어야 한다"가 내용이다.

## 2. 경로에 따라 신뢰도가 갈린다

여기가 이 항목의 핵심이다.

| 경로 | 근거 | 신뢰도 |
|---|---|---|
| 라벨 사진 | 제조사가 법적 책임을 지고 적은 **알레르기 표시란** | 높음 |
| 제품명 입력 | 공공DB의 **원재료명에서 짚어낸 것** | 낮음 |

공공DB(C002)에는 **알레르기 필드가 없다.** 원재료명뿐이다.
그래서 제품명으로 찾는 경로에서는 우리가 원재료명을 보고 추론하는 수밖에 없고,
그 추론은 틀릴 수 있다.

**알레르기에 대해서는 제품명 경로로 단정하지 않는다.** 라벨을 보라고 안내한다.

## 3. 부분 일치가 특히 위험하다

실제로 걸린 오탐이다. 첨가물에서는 불편한 정도지만 알레르기에서는 사람이 다친다.

| 잘못 걸린 것 | 붙은 항목 | 실제 |
|---|---|---|
| 메밀가루 | 밀 | 메밀은 밀이 아니다 |
| 호밀가루 | 밀 | 호밀은 밀이 아니다 |
| 밀납 · 밀크향 · α아밀라아제 · 밀크씨슬 | 밀 | 글자만 겹친다 |
| 둥굴레 · 인동덩굴 · 굴비살 | 조개류 | |
| 식물성크림 | 우유 | 식물성이다 |
| 대우유부침가루 | 우유 | `대우` + `유부침가루` |
| 돼지사골 | 쇠고기 | 돼지다 |
| 붉은멍게추출물 · 올방게분말 | 게 | |

그래서 **포함 규칙과 제외 규칙을 함께** 둔다. 규칙은 `data/curated/allergen_map.csv`.

## 4. 확신을 두 단계로 나눈다

| 단계 | 뜻 | 예 |
|---|---|---|
| **직접** | 성분 자체이거나 직접 유래물 | 밀가루→밀, 탈지분유→우유, 돈지→돼지고기 |
| **추정** | 대개 들어가지만 제품에 따라 다름 | 간장→대두, 햄→돼지고기, 버터→우유 |

추정은 **있다고 단정하지 않는다.** 장류는 대개 대두가 들어가지만 밀만 쓰는 제품도 있고,
버터·치즈는 대체유지를 쓴 제품이 있다. 「땅콩또는견과류가공품」은 둘 중 무엇인지
라벨로 알 수 없다 — 이 표기 하나가 13,366회 등장한다.

## 6. 범위에 대한 확인 필요

PRD는 **알레르기 모드를 MVP에서 제외**하기로 했다. 이 작업은 그 결정을 뒤집는 것이 아니다.

여기서 만든 것은 **성분 사전의 일부**다. 밀·우유·대두·돼지고기는 알레르기와 무관하게
사용자가 자주 제한하는 성분이고, 표시 의무 덕분에 **라벨에 반드시 나온다**는 점이
판정 신뢰도에 직접 영향을 준다. 「확인 불가」로 빠질 확률이 낮은 성분군이다.

알레르기 모드(교차오염 주의 문구 해석, 미량 혼입 경고 등)를 만들 것인지는 별도 결정이다.
