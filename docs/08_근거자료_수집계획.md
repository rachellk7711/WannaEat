# 08. 근거 자료 수집 계획 (C층)

작성일: 2026-09-14 · 대상: 성분 카드의 **역할(용도)** 과 **각국 규제현황**

> 성분 사전 A층(식별)·B층(판정)과 달리, 이 층은 **사용자가 성분 이름을 눌렀을 때 보이는 내용**을 만든다.
> 제품의 차별점이 여기 있다 — 다른 앱은 점수를 주고, 우리는 근거를 준다.

---

## 1. 무엇을 채우나

성분 하나당 이렇게 채운다.

```
알룰로오스 (알룰로스)                    [피해요] [알려만줘요]
희소당 감미료 · 체내에서 대사되지 않음
사용기준: 국내 제한 없음 · 미국 GRAS · EU 신소재식품 승인(2021)   [식약처][FDA][EFSA]
                                                          [자세히 ▾]
```

| 요소 | 내용 | 출처 성격 |
|---|---|---|
| **역할·용도** | 감미료·증점제·보존료 등 | 국내 고시 |
| **국내 기준** | 사용기준 (어떤 식품에 얼마까지) | 식약처 |
| **해외 기준** | ADI, GRAS, 승인 여부 | EFSA·FDA·JECFA |
| **발암성 분류** | Group 1~3 (해당 시) | IARC |
| **혼동 정정** | 필요한 경우만 | 규제기관 문서 |

⚠️ **유해성은 우리가 서술하지 않는다.** 기관의 결론만 인용한다 (`02_법무-표현설계` §4-A).

## 2. 출처별 수집 방법 — 자동화 가능한 것이 생각보다 많다

당초 28시간 전부 수작업으로 잡았으나, **기계로 받을 수 있는 것이 절반 가까이 된다.**

| 출처 | 주는 것 | 형태 | 자동화 | 비용 |
|---|---|---|---|---|
| **`I0950` 식품첨가물공전** | 국내 품목별 기준·규격 6,895건 | 오픈API | ✅ 자동 | 0원 |
| **`I1101` 식품첨가물의 기준 및 규격** | 국내 사용기준 | 오픈API | ✅ 자동 | 0원 |
| **EFSA OpenFoodTox** | **화학물질 8,006종 · ADI 등 위해평가 11,357건** | Zenodo 공개 데이터셋 | ✅ 자동 | 0원 |
| **FDA GRAS Notice Inventory** | GRAS 통지 목록·FDA 회신 | 웹 DB (목록 조회) | ✅ 반자동 | 0원 |
| **IARC Monographs** | 발암성 분류 Group 1~3 | 공개 목록 | ✅ 반자동 | 0원 |
| **Codex GSFA** | 식품 범주별 국제 사용기준 | 온라인 DB | ⚠️ 반자동 | 0원 |
| **JECFA 평가서** | 일일섭취허용량 평가 근거 | PDF | ❌ 수작업 | 0원 |
| **국가법령정보센터** | 고시 원문 (인용용) | 웹 | ❌ 수작업 | 0원 |

**전부 무료다.** LLM 크레딧도 필요 없다 — 이 단계는 자료를 받아 정리하는 일이지 추론이 아니다.

## 4. 작업 순서

### 1단계 — 국내 기준 (19시 이후) · 2h

```
I0950 식품첨가물공전  6,895건 ┐
I1101 기준 및 규격           ├→ 첨가물 품목명 + 기준·규격
                             ┘
   ├→ (A층) 미매칭 토큰 자동 매칭 — 첨가물이 미매칭 등장의 26.9%
   └→ (C층) 성분 카드의 "국내 기준" 줄
```

**한 번 받아 두 곳에 쓴다.** A층 매칭률도 같이 오른다.

### 2단계 — 해외 기준 자동 수집 · 3h

| 순서 | 대상 | 결과 |
|---|---|---|
| 1 | EFSA OpenFoodTox (Zenodo) | 물질별 ADI·평가 출처를 표로 |
| 2 | IARC 분류 목록 | 발암성 Group 매핑 |
| 3 | FDA GRAS Inventory | GRAS 통지 번호·물질명 |

우리 성분 사전의 표준명·영문명과 **물질명으로 조인**한다. 영문명은 `I2520`에 이미 있다.

### 3단계 — 감미료 10종 정밀 작성 · 12h

자동 수집으로 채워지지 않는 부분만 사람이 읽는다.

| 성분 | 왜 정밀 작업이 필요한가 |
|---|---|
| 에리스리톨 | 2023년 연구 논란 — **개별 논문 인용 금지**, 기관 평가만 |
| 알룰로오스 | 국내·미국·EU 지위가 다름 |
| 수크랄로스·아스파탐 | 기관 결론이 갈림 |
| 말티톨·자일리톨·소르비톨 | 당알콜 — 혈당 반응이 쟁점 |
| 스테비올배당체 | `효소처리스테비아`(3.9만회)와 표기·지위 정리 필요 |
| 아세설팜칼륨·폴리글리시톨시럽 | 자료가 적음 |

### 4단계 — 식품원료 · 6h

설탕·물엿·밀가루·전분·유지류. **허용기준 개념이 없으므로** 영양성분(국가표준식품성분표)과 WHO 권고로 채운다.

### 5단계 — 출처 보관 · 2h

```
docs/refs/
├── _index.md    출처 대장 — 성분·기관·문서명·발행연도·접근일·DOI·로컬파일
├── kr/          식약처 고시·공전 발췌
├── eu/          EFSA 평가서 PDF
├── us/          FDA GRAS 회신
└── intl/        JECFA·IARC·Codex
```

**URL만 두지 않는다.** 규제 문서는 개정되고 링크는 죽는다. 인용 시점의 원문을 남긴다.
