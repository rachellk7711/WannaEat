# 성분군 지도 — 어디에 무엇이 남았나

근거 카드(C층)를 어느 순서로 채울지 정하기 위한 지도다.
숫자는 우리 제품 DB(169만 건)에서 원재료명이 **몇 번 등장했나**로 센다.
종수가 아니라 등장 횟수로 봐야 사용자가 실제로 마주칠 확률에 비례한다.

작성 2026-09-15 · 등장 50회 이상 5,946종 · 총 등장 1,055만
정정 2026-09-17 · 검증(`docs/21`) 후 재생성한 데이터로 모든 숫자를 다시 쟀다.
처음 판의 "국내 사용기준 94.1%" 는 빈칸을 "제한 없음" 으로 채워 부풀린 숫자였다.

## 2. 가장 큰 덩어리는 성분이 아니다

**등장의 18.9%가 「집합 표기」다.** 개별 물질명이 아니라 묶음 이름이다.

| 표기 | 등장 |
|---|---:|
| 복합조미식품 | 270,477 |
| 소스 | 231,076 |
| 합성향료 | 182,470 |
| 기타가공품 | 176,849 |
| 혼합제제 | 141,501 |
| 향료 | 89,958 |
| 합성착향료 | 54,695 |
| 천연향료 | 26,289 |

향료 계열만 합쳐 **35만 회**다. 「합성향료」에 어떤 물질이 들어 있는지는
라벨로 알 수 없고, 표시기준상 알릴 의무도 없다.

**이건 근거 카드로 풀 수 있는 문제가 아니다.** 아무리 사전을 채워도 여기는 비어 있다.
이미 파악한 「하위 원료 미표시 복합원재료 34%」와 같은 성질의 한계이고,
제품은 이것을 **숨기지 말고 「확인 불가 N개」로 함께 보여주는** 방식으로 다룬다.

`혼합제제` 는 I1020 에서 복합원료(사용가능)와 식품첨가물(사용불가) 기록이 함께 잡힌다.
집합 표기이므로 판정 대상에서 빼야 한다.

## 3. 사람이 확정한 근거 (38종)

| 성분군 | 성분 |
|---|---|
| 감미료 15종 | 별도 문서 `16_근거자료집_감미료.md` |
| 당류 3종 | 자당(설탕)·과당·포도당 — WHO 유리당 권고, 보건복지부 2025 섭취기준 |
| 조미료 1종 | L-글루탐산나트륨 |
| 증점·유화제 6종 | 잔탄검·변성전분·카라기난·글리세린·레시틴·결정셀룰로스 |
| 보존료 2종 | 파라옥시안식향산에틸·아질산나트륨 |
| 착색료 9종 | 카라멜색소(그룹)·카라멜색소Ⅲ·파프리카추출색소·치자황색소·황색4호·황색5호·적색40호·청색1호·이산화티타늄 |
| 산도조절제 1종 | 폴리인산나트륨(인산염류) |
| 영양강화 1종 | 비타민 C |

행마다 `검토 상태` 가 있다. 카드에는 확인된 행만 내보낸다
(`data/curated/evidence_manual.csv`, 2026-09-17 기준 39행 — 경미 수정·원문 확인까지 반영, `docs/21` §11).

특히 기록해 둘 것

- **L-글루탐산나트륨** — 그룹 ADI 30mg/kg 체중/일(글루탐산 기준). EFSA는
  **일부 인구집단의 섭취량이 이 ADI뿐 아니라 사람에게서 이상반응이 보고된 용량도 넘는다**고
  지적했다. JECFA 는 같은 물질에 수치 ADI 를 두지 않았다.
- **치자황색소** — 국내 공전에 수록돼 사용가능이지만, 받아 둔 EU 식품첨가물 목록(412종)에는 없고
  FDA 목록에도 착색료로는 없다. 지역마다 판단이 갈리는 성분은 한 기관만 인용하면 사실을 왜곡한다.
  (다른 나라의 허용 여부는 확인하지 않았다)
- **당류** — ADI가 아니라 **섭취 권고**다. 하루 식단 전체에 대한 비율이라,
  라벨만 보고 "넘었다/안 넘었다"를 말할 수 없다. 카드에 권고를 적되 판정에는 쓰지 않는다.
  보건복지부 권고는 **2025 섭취기준**(2025-12-31 발표)이 현행이다 —
  총당류 "10~20% 이내" 를 "20% 이내" 로, 첨가당 "10% 이내 섭취" 를 "10% 이내 제한" 으로 바꿨다.
- **비타민 C** — 2025 섭취기준도 상한 2 g/일을 유지했다(원문 확인). 식이보충제 섭취자의 3.9%가 넘는다.
- **이산화티타늄** — EFSA 2021: 식품첨가물로서 더는 안전하다고 볼 수 없다. OpenFoodTox 에는 이 결론이 없다.

## 4. 기준의 종류가 다르다는 문제

값만 적으면 틀린다. 같은 한도가 기준을 달리해 다른 숫자로 적힌다.

| 성분 | 값 | 무엇 기준인가 |
|---|---|---|
| 아질산나트륨 | 0.07 / 0.1 | 아질산 이온 기준 / 아질산나트륨 기준 — **같은 한도** |
| 사카린나트륨 | 9 / 5 | 유리 이미드 기준 / 사카린나트륨 기준 |
| L-글루탐산나트륨 | 30 | 글루탐산 기준 (근거가 된 NOAEL 3,200 은 MSG 기준) |
| 인산염류 | 40 | 인(P) 기준 |
| 파프리카추출색소 | 24 / 1.7 | 추출물 기준 / 카로티노이드 기준 — **같은 시험의 NOAEL 을 카로티노이드 7.1% 로 환산** |

**정정** — 처음 판에는 파프리카추출색소를 "같은 성분에 기준이 둘인 사례" 로 들었다. EFSA 근거 문장을 확인하니
두 값은 같은 시험에서 나온 한도를 다른 기준으로 표시한 것이었다. 위 표처럼 고쳐 적는다.

`efsa_adi.csv` 의 `basis` 칸에 EFSA 원문의 근거 문장을 싣는다.
처음에는 필드 경로 오류로 이 칸이 전부 비어 있었고, 2026-09-17 에 고쳐 1,153행 중 620행에 들어갔다.
카드에는 **숫자와 기준을 반드시 붙여서** 적는다.

## 5. 자동으로는 더 못 가는 지점

- **국내 기록은 94.1% 에 있지만, 조건 문구는 32.0% 뿐이다.** 빈칸은 "제한 없음" 이 아니라
  "확인 안 됨" 이다. 사용 상태(사용가능·사용불가·제한적사용)는 따로 싣는다.
- **국제 근거는 17.5%** 다. EFSA OpenFoodTox 의 ADI 원 기록 1,153건 중 식품 분야는 187건뿐이고
  나머지는 농약·사료 평가다. FDA·JECFA·EU 를 더해도 한국어 성분명과 잇는 단계가 병목이다.
- 영문명이 서로 다른 물질을 가리키는 경우(소르비탄지방산에스테르 → 5종)는 값을 붙이지 않고
  `후보 여러 개` 로 둔다.

자동 처리에서 실제로 난 오류를 기록해 둔다.

| 성분 | 자동 결과 | 실제 |
|---|---|---|
| 잔탄검 | 자료 부족 | **수치 불필요.** 첫 결론 행이 ADI가 아니라 생산균주 얘기였다 |
| 아세설팜칼륨 | 9 | **15.** 옛 평가와 재평가가 함께 들어 있었다 |
| 소브산칼륨 | 25 (2019) | **11 (2019).** 옛 값에 새 평가서 연도가 붙어 있었다 |
| 비타민b | 리보플라빈 | **비타민 B2·B12·B6·B1 이 한 토큰으로 합쳐져 있었다.** 끝 숫자를 지우는 정규화 탓 |
| 쑥·천궁 등 14건 | 제한 없음 | **사용불가·제한적사용.** 빈칸을 제한 없음으로 채운 탓 |
