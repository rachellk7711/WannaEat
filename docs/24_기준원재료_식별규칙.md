# 기준 원재료 식별 규칙

사용자가 고른 기준 원재료가 제품 원재료명에 **들어 있는지**를 가려내는 규칙이다. MVP 판정의 핵심이다.
알레르기는 다루지 않는다(2026-09-17 결정).

작성 2026-09-17 · 확장 2026-09-18 (26 → 62개) · **초안** — 사람 검수 전이다.

---

## 1. 왜 필요한가

검증(`docs/21` §8-1)에서 라벨 표기 변형을 놓치는 문제가 드러났다.
`돼지고기`·`소고기`·`밀가루` 같은 **완성된 단어만** 보면 이런 표기가 빠진다.

```
돼지등심 · 돼지뒷다리 · 돈육앞다리살 · 소갈비 · 소양지 · 한우채끝 · 박력분 · 중력분 · 액상과당
```

반대로 **넓은 부분 일치**는 엉뚱한 것을 잡는다.

```
당 → 당근·당귀·당면     밀 → 밀크·밀납·아밀라아제     콘 → 글루콘산
유 → 우유               우육 → 새우육수               떡 → 떡갈비
```

## 2. 기준 목록 (62개)

토스 이용자 전체에 공개하므로 **저탄고지·카니보어 프리셋은 두지 않는다**(2026-09-17 결정).
사용자는 분류 6개 → 소분류에서 기준을 고르거나 검색한다(§2-1). 분류는 `docs/22_기준설정_분류_제안.md` 를 따른다.
기준마다 강도는 **피해요 / 알려만 줘요** 두 단계다. 판정 결과(아래 네 갈래)와는 따로 저장한다.

| 분류 | 기준 |
|---|---|
| 곡물·전분 (11) | 밀 · 쌀 · 옥수수 · 보리·맥아 · 귀리 · 메밀 · 기타 잡곡 · 감자·고구마 · 전분 · 덱스트린·말토덱스트린 · 난소화성말토덱스트린 |
| 당류·감미료 (11) | 설탕 · 과당 · 포도당 · 물엿·시럽 · 올리고당 · 꿀 · 유당 · 기타 당류 · 알룰로스·타가토스 · 당알코올 · 고감미 감미료 |
| 콩·두류 (2) | 대두(콩) · 기타 콩류 |
| 동물성 원료 (9) | 돼지고기 · 소고기 · 닭고기 · 오리·양·염소 등 기타 육류 · 어류 · 갑각류·조개·오징어류 · 달걀 · 우유·유제품 · 젤라틴·콜라겐 |
| 기름·견과·씨앗 (18) | 대두유 · 옥수수기름 · 카놀라유 · 해바라기유 · 포도씨유 · 면실유 · 미강유 · 홍화유 · 올리브유 · 코코넛오일 · 참기름·들기름 · 기타 식물성 기름 · 팜유 · 쇼트닝·마가린 · 동물성 지방 · 땅콩 · 견과류 · 씨앗류 |
| 첨가물·기타 (11) | 향료 · 향미증진제(MSG 등) · 보존료 · 산화방지제 · 발색제(아질산·질산염) · 증점·안정·유화제 · 카라기난 · 착색료 · 타르색소 · 산도조절·팽창제 · 인산염 |

**한 표기가 여러 기준에 걸릴 수 있다.** `버터` = 우유·유제품 + 동물성 지방, `카라기난` = 카라기난 + 증점제,
`폴리인산나트륨` = 인산염 + 산도조절제, `감자전분` = 감자·고구마 + 전분. 사용자가 고른 기준마다 따로 판정한다.

**기준 사이 경계**

- `대두(콩)` 은 대두유(기름)를 포함하지 않는다. 기름은 `대두유` 로 따로 고른다. `대두레시틴` 은 대두에 포함한다
- `씨앗류` 는 씨앗 기름을 포함하지 않는다(`참깨유` 는 참기름·들기름). `땅콩` 은 견과류와 따로다
- `야자유` 는 식품공전상 코코넛오일이다. 처음 판에 팜유로 넣었던 것을 옮겼다
- `맥아당` 은 보리가 아니라 기타 당류, `환원물엿` 은 물엿이 아니라 당알코올로 본다
- 유제품·달걀·땅콩·갑각류는 **식단 선택 항목**이다. 알레르기 표시·판정으로 쓰지 않는다

### 2-1. 화면 구성 결정 (2026-09-18)

**원칙 — 판정 단위는 잘게, 화면 묶음은 따로.** 잘게 나눈 기준은 나중에 묶을 수 있지만,
묶어 둔 기준을 다시 나누려면 규칙·검수·사용자 저장값을 전부 다시 만들어야 한다.
그래서 규칙은 62개 기준 그대로 두고, 화면 묶음은 `data/curated/criteria_layout.csv` 한 파일에서만 정한다.
이 파일을 고쳐도 규칙·사용자 설정·이력은 바뀌지 않는다.

| 분류 | 소분류 (전체 선택) |
|---|---|
| 곡물·전분 | 곡물 7 (○) · 감자·전분류 4 (○) |
| 당류·감미료 | 당류 8 (○) · 대체 감미료 3 (○) |
| 콩·두류 | 콩류 2 (○) |
| 동물성 원료 | 육류 4 (○) · 해산물 2 (○) · 달걀·유제품 2 (○) · 동물 유래 원료 1 (×) |
| 기름·견과·씨앗 | 종자유 8 (○) · 그 밖의 기름·지방 7 (×) · 견과·씨앗 3 (○) |
| 첨가물·기타 | 자주 찾는 성분 5 (○) · 용도별 첨가물 6 (○) |

**결정 1 — 기름 18개는 소분류 세 개로 나눈다.**

- `종자유` 8개(대두·옥수수·카놀라·해바라기·포도씨·면실·미강·홍화)는 종자유를 피하는 사람들이 흔히 꼽는
  8종과 같다. 이 사용자들은 "종자유 전부" 로 고르므로 **전체 선택**을 준다.
- `그 밖의 기름·지방`(올리브·코코넛·팜·참기름·쇼트닝·동물성 지방·종류 미표기)은 성격이 제각각이다.
  올리브유와 동물성 지방을 한 번에 피하려는 사람은 드물다 → **개별 선택만**.
- `견과·씨앗` 은 기름이 아니지만 분류 제안서(`docs/22_기준설정_분류_제안.md`)의 "기름·견과·씨앗" 을 따른다.

**결정 2 — 첨가물은 두 층을 모두 둔다.** "자주 찾는 성분" 과 "용도별 첨가물" 이다.

- 자주 찾는 성분 5개(MSG·타르색소·아질산·카라기난·인산염)는 사람들이 **이름으로** 피한다.
  용도별 첨가물 6개(보존료·산화방지제·착색료·증점제·산도조절제·향료)는 **범주로** 피한다. 둘 다 실제 수요다.
- 한쪽만 두면 나중에 다른 쪽을 규칙부터 새로 만들어야 한다. 둘 다 이미 만들어 측정까지 마쳤다.
- 겹침은 데이터로 표시한다. 카탈로그의 `includedIn` 에 직접 표기의 90% 이상이 다른 기준에도 걸리는 경우를 적었다 —
  `타르색소 ⊂ 착색료`, `카라기난 ⊂ 증점제`, `인산염 ⊂ 산도조절제`, `유당 ⊂ 우유·유제품`.
  둘 다 고른 사용자에게 결과 화면은 **같은 원재료 표기를 한 줄로 보여주고, 걸린 기준을 함께 적는다.**

**결정 3 — 난소화성말토덱스트린은 따로 둔다.** 식이섬유 원료로 쓰이고(건강기능식품 기능성원료이기도 하다),
말토덱스트린과 섞으면 "덱스트린을 피한다" 는 사용자에게 식이섬유까지 걸린다. 반대로 합쳐 두면 나중에 나눌 수 없다.
대신 같은 소분류(감자·전분류)에 나란히 두고 설명을 붙인다.

**결정 4 — 올리고당은 당류에 둔다.** 이견이 있는 것은 "피할지 말지" 이지 "무엇인지" 가 아니다.
기준이 따로 있으므로 사용자가 당류 전체를 고른 뒤 올리고당만 빼면 된다.
`유당` 도 당류에 두되 우유·유제품에 포함된다는 사실을 `includedIn` 으로 알린다.

**결정 5 — 전체 선택은 소분류 ID 로 저장한다.** "종자유 전체" 를 고르면 8개 ID 가 아니라 `seed_oils` 로 저장하고,
판정할 때 그 시점 카탈로그로 펼친다. 나중에 종자유 기준이 늘어도 사용자의 뜻이 유지된다 —
8개 ID 로 저장하면 새 기준이 빠져 **"없음" 이 잘못 나가는 쪽**으로 틀린다.
전체 선택한 소분류 안의 기준 하나를 사용자가 따로 바꾸면(빼거나 강도를 바꾸면) 그 소분류는 개별 기준 목록으로 풀어 저장한다.
이력에는 판정 당시 펼쳐진 기준 목록과 `rulesetVersion` 을 함께 남긴다.

**결정 6 — 기준 ID 는 바꾸지 않는다.** 이름·소분류는 바꿔도 되지만 ID(`soy_oil` 등)는 사용자 저장값과 이력이 참조한다.
기준을 없앨 때는 지우지 않고 `폐지` 로 표시한다.

**실물 라벨로 확인할 것** — 표시기준은 일부 첨가물(보존료·산화방지제 등)을 용도명과 함께 적게 한다
(예: `산화방지제(토코페롤)`). 이런 표기는 라벨 사진에서 괄호 밖 용도명이 곧 발견 근거가 되어,
공공DB 측정보다 「확인 필요」가 줄어들 것으로 본다. 용도명 병기 대상 목록은 표시기준 원문으로 확인해야 한다(G3 라벨 점검).

## 3. 규칙

규칙 파일은 `data/curated/criteria_rules.csv` 다. 한 줄이 규칙 하나다.

| 규칙 | 뜻 | 예 |
|---|---|---|
| 정확 | 토큰 전체가 같다 | `엿` · `쌀` · `우지` |
| 접두 | 그것으로 시작한다 | `돼지…` · `소갈비…` · `계육…` |
| 접미 | 그것으로 끝난다 | `…분당` |
| 포함 | 안에 들어 있다 | `…설탕…` · `…한우…` |
| 제외 | 들어 있으면 그 기준에서 뺀다 (가장 먼저) | `돼지감자` · `밀크` · `떡갈비` |
| 제외접미 | 그것으로 끝나면 뺀다 | 대두 기준의 `…대두유` (`대두유래` 는 남긴다) |

**구체적인 규칙이 이긴다.** 정확 > 접두·접미 > 포함. 같은 급이면 직접 > 추정.
Codex 검증 보고서가 지적한 "넓은 부분 일치가 구체 규칙을 덮어쓰는" 문제를 구조로 막는다.

**확신 두 단계**

| 확신 | 판정 결과 | 예 |
|---|---|---|
| 직접 | **발견** | 백설탕 · 박력분 · 돼지등심 · 한우양지 |
| 추정 | **확인 필요** | 당류가공품 · 빵가루 · 햄 · 사골 · 가공유지 |

**공통 규칙**

1. **향료 표기**(`흑설탕향`·`쇠고기맛분말`·`치킨후레바`)는 그 원재료가 들었다는 뜻이 아니다.
   그렇다고 빼면 소고기를 피하는 사용자에게 `쇠고기맛분말` 이 "없음" 으로 나간다.
   **추정(확인 필요)으로만** 올린다. 향신료는 향료로 보지 않는다.
2. **추정 규칙은 양념 맥락이면 적용하지 않는다.** `우동소스`·`라면스프`·`비프시즈닝분말` 은
   면·고기가 아니라 양념이다.

3. **LLM 표준명 경유.** 규칙에 걸리지 않은 토큰은 성분 사전 LLM 분류(`05`)가 붙인 표준명으로 한 번 더
   규칙을 적용한다. 여기서 걸리면 직접이어도 **추정(확인 필요)으로 낮춘다** — LLM 판단은 사람이 보지 않았다.
   규칙 칸에 `표준명경유(…)` 로 남는다. 937개 토큰 · 등장 2,992회가 이 경로로 새로 이어졌다
   (`마아가린`·`찹살`·`액상당밀` 같은 오타·변형).
4. 물엿·시럽에 `당밀`(직접)과 `시럽` 단독(추정)을 더했다. 시럽 단독은 무엇의 시럽인지 알 수 없다.

5. **`또는` 표기는 추정으로 낮춘다.** `땅콩또는견과류가공품` 은 땅콩인지 견과인지 알 수 없다.
6. **향료 기준은 예외다.** 1번 규칙(향료 표기 → 추정)은 향료를 직접 고른 사용자에게는 거꾸로다.
   `딸기향` 은 향료 기준에서 발견이다.

**묶음 표기** (`data/curated/opaque_terms.csv`)

`복합조미식품`·`혼합제제`·`향료`·`…가공품`·`…조제품`·`…또는…` 처럼 무엇이 들었는지 알 수 없는 표기.
2,168종 · 원재료 등장의 **18.4%**.

**읽는 법**

- **"놓친 발견"** 은 예전 방식이면 사용자에게 **"없음"** 으로 나갔을 제품이다. PRD 의 품질 기준
  "거짓 안심 0건" 에 정면으로 걸린다. 소고기 15.4만 · 전분 13.1만 · 돼지고기 12.5만 · 쌀 8.4만 · 과당 5.9만 건.
- **"확인 불가"** 가 기준마다 20~37% 다(설탕 20% · 나머지 30~37%). 기준 원재료는 보이지 않지만 속을 알 수 없는 표기가 섞인 제품이다.
  이 제품들에 "없음" 이라고 말하면 안 된다. 앞서 표본에서 잰 「하위 원료 미표시 복합원재료 34%」와 같은 규모다.
- **쇼트닝·마가린은 확인 필요가 발견보다 많다.** `가공유지`·`식물성유지` 처럼 어떤 기름인지 적지 않는 표기 탓이다.
  `기타 식물성 기름` 도 같다(발견 1,259 · 확인 필요 25,657).
- **추정이 큰 기준** — 달걀 확인 필요 2.1만(`마요네즈`), 대두 2.6만(`고추장`·`레시틴`), 우유 1.9만(`식물성크림`),
  산화방지제 1.9만(`토코페롤`·`녹차추출물` — 영양강화 목적일 수 있다), 어류 1.7만(`액젓` — 새우젓일 수 있다),
  땅콩·견과류 각 1만(`땅콩또는견과류가공품`).

## 5. 한계

- **무작위 표본으로만 검수했다.** 기준마다 14개씩, 새 기준은 등장 상위 45개도 함께 봤다. 전수 검수가 아니다.
  2026-09-18 확장 때 표본에서 찾아 고친 오탐 — `가수분해물`→해산물(`해물`), `차조기`→잡곡(`조`),
  `참깨유과`→참기름, `혼합유당`·`혼합유산균`→식물성 기름(`혼합유`), `올레인산`·`카제인산나트륨`→인산염,
  `deveinedtailoff`→산화방지제(`edta`), `체중조절용조제식품`→팽창제(`중조`), `갈매보리수`→보리,
  `마카젤라틴화분말`→젤라틴, `잉카피넛`→땅콩, `비카민c`(오타)→착색료(`카민`).
- **오타 표기**는 LLM 표준명 경유로 일부만 잡힌다(`수테비아`·`솔비틀` → 추정). 전부 잡히지는 않는다.
- **실물 라벨과 대조하지 않았다.** PRD 의 품질 점검(라벨 20장)이 필요하다.
- **괄호 안 내용.** 토큰화(`04` 의 `split("(")[0]`)는 괄호 안을 버린다. 확인해 보니 공공DB 의 괄호는
  하위 원료 목록이 아니라 **"어떤 것인지" 를 밝히는 한정어**였다 — `콩기름(대두유)` · `비타민(고시형)` ·
  `정제소금(재제조소금)` · `식용유지(유채유 또는 카놀라유)` · `천연향료(Pepper, black)`.
  측정(`19`)은 이 한정어에도 규칙을 적용한다. 부모가 향료 표기면 추정으로만 본다.
  새로 찾은 제품은 적다(덱스트린 677 · 전분 334 · 옥수수 271 · 돼지고기 145 · 설탕 144).
  `(대두유)` 7만 건은 거의 전부 `콩기름(대두유)` 라 이미 잡혀 있었다.
  **라벨 사진은 사정이 다르다.** 실물 라벨은 복합원재료의 하위 원료를 괄호 안에 적으므로,
  사진 경로에서는 괄호 안을 하위 원료로 읽어야 한다. 공공DB 와 규칙을 나눠야 한다.
- `사골` 은 대개 소뼈지만 확정할 수 없어 추정이다. 이런 판단은 사람이 계속 다듬어야 한다.
