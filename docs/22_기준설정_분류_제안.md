# 알고먹을래? 기준 설정 분류 제안

상태: 2026-09-17 논의 초안. 사용자 선택을 돕는 화면 분류이며, 영양성분표의 탄수화물·단백질·지방 함량이나 안전성 판정으로 사용하지 않는다. 1차 출시 범위는 개인이 선택한 원재료의 표시 여부 대조다.

## 권장 화면 분류

| 화면 분류 | 하위 선택 예시 |
|---|---|
| 곡물·전분 | 밀 및 밀 유래, 쌀, 옥수수, 보리·귀리, 감자·고구마·타피오카, 기타 전분 |
| 당류·감미료 | 설탕·포도당·과당, 시럽·물엿, 당알코올, 고감미료 |
| 콩·두류 | 대두, 완두, 병아리콩·렌즈콩, 기타 콩, 원료가 확인된 식물성 단백 |
| 동물성 원료 | 소·돼지·닭 등 육류, 어류·해산물, 달걀, 우유·유제품 |
| 기름·견과·씨앗 | 식물성 기름, 동물성 지방, 견과, 씨앗 |
| 첨가물·기타 | 보존·산화방지, 증점·안정·유화, 착색·향료, 산도조절·조미, 과일·채소·향신료 등 직접 검색 |

첫 화면에는 이 6개와 `원재료 직접 검색`만 보여준다. 하위 목록은 자주 찾는 항목부터 보여주고, 사용자가 군 전체를 선택하면 포함되는 원재료와 예외를 펼쳐서 확인하게 한다. 저탄고지·카니보어는 시작용 프리셋으로 제공하되, 저장 전 각 항목을 사용자가 수정·확정한다.

## 분류와 매칭 원칙

- 영양소 이름은 원재료의 단일 소속으로 삼지 않는다. 우유는 유제품이면서 단백질과 지방을 포함하고, 대두도 여러 영양소를 포함한다. 화면 분류는 탐색용이고 판정은 **확정된 원재료 ID와 확인된 유래 관계**로 한다.
- 한 원재료에 여러 태그를 허용한다. 예: 버터 = `우유·유제품` + `동물성 지방`; 땅콩 = `두류` + 화면 탐색용 `견과·씨앗`. 중복 노출이 가능해도 저장된 제한 규칙은 한 번만 적용한다.
- `밀`을 고르면 박력분·강력분 등 확인된 밀 유래 원재료를 포함한다. `메밀`, `밀크`처럼 글자가 겹칠 뿐인 이름은 제외한다. `분리식물성단백`처럼 원료가 특정되지 않으면 대두·완두 어느 쪽에도 자동 배정하지 않는다.
- `향료`, `혼합제제`, `기타가공품`처럼 하위 원료를 알 수 없는 집합 표기는 `첨가물` 군에 넣어 안심 판정하지 않는다. 결과에 `내용 확인 불가`로 별도 표시한다.
- **2026-09-18 사용자 결정:** 설정 표기는 `피해요 / 알려만줘요` 2단계로 확정한다. `피해요`는 발견 시 표시 위치와 관계없이 기준 불일치에 포함하고, `알려만줘요`는 발견 사실을 안내하되 불일치에는 포함하지 않는다. 미선택 원재료는 개인 기준 대조 대상에서 제외하며 세 번째 설정 버튼으로 만들지 않는다. 표시 위치를 양이나 허용 여부로 해석하지 않으며 확인 불가는 별도 표시한다.
