# 내 기준 미니사전 — 62개 항목 표시안

문구·화면 구성 검토안 · 확인일 **2026-10-02**

앱에 연결할 짧은 문구는 [criteria_glossary.csv](../data/curated/criteria_glossary.csv)에 있다. 현재 기준 목록의 **62개 ID와 순서**에 맞췄다. 아래 표의 **역할·쟁점은 CSV와 같은 문구**이며, 원료·제조 방식은 이전 요청에 따라 남겨 둔 상세 참고 정보다.

62개는 개별 화학물질의 수가 아니라 사용자가 선택하는 기준 수다. ‘보존료’처럼 여러 물질의 묶음과 ‘카라기난’처럼 특정 물질의 기준이 함께 있다. 기준명은 [criteria_rules.csv](../data/curated/criteria_rules.csv), 순서는 [criteria_layout.csv](../data/curated/criteria_layout.csv)와 대조했다.

## 전달 형식과 문장 원칙

| CSV 열 | 내용 |
|---|---|
| 기준ID | 현재 목록과 같은 ID. 예: wheat, carrageenan. 중복·누락 없이 62행. |
| 역할(한 줄) | 원료와 음식에서 하는 일을 한 문장으로 표현. 현재 최대 29자. |
| 쟁점(1~2줄) | 구체적인 확인·기피 이유와 필요한 한계. 현재 최대 56자, 두 문장 이내. |
| 출처 | 쟁점을 뒷받침하는 기관·자료명과 원문 URL. 여러 자료는 세미콜론으로 구분. |
| 확인일 | 원문 확인 날짜, YYYY-MM-DD. 원문의 발표·평가 연도와 구분. |

- **위해성을 단정하거나 건강 효과를 약속하지 않는다.** 원료·공정에 대한 선호와 연구 결과를 구분한다.
- **알레르기 내용은 MVP 문구에서 제외한다.** 이번 MD의 성분 설명과 CSV 모두에 적용했다.
- **쟁점을 숨기지 않는다.** 부분경화, 추출·정제, 소화 불편, 개별 첨가물의 평가처럼 판단에 필요한 내용을 구체적으로 쓴다.
- 각 출처는 공정·조성·평가 등 **사실 부분**의 근거다. ‘피하려는 선택’은 가능한 선택 맥락을 설명하는 편집 문구이며, 기피 인구의 규모나 빈도를 주장하지 않는다.
- 모든 항목에 위험성 주장을 억지로 만들지 않는다. 별도의 위해 근거보다 원료 유래·배합·가공 정도가 핵심인 경우 그 차이를 설명한다.
- 한 줄·두 줄은 휴대폰 표시 목표다. 글자 수를 줄여 두었으며, **실제 줄 수는 화면 폭·글꼴·접근성 글자 크기로 확인**한다. 내용을 잘라 숨기는 말줄임으로 맞추지 않는다.

CSV는 문구 전달용이다. 이번 변경으로 앱에 자동 적용되지는 않는다.

## 어디에서 보여줄까

### ① 결과 화면: 성분 카드를 누르면 하단 창

가장 먼저 적용할 위치다. “왜 이게 걸렸지?”에 답하도록 제품에서 발견한 표기를 설명과 함께 보여준다.

| 순서 | 화면 내용 | 표시 원칙 |
|---|---|---|
| 제목 | 실제 발견 성분명 · 피해요/알려만줘요 | 상태는 사용자가 정한 기준이며 위해성 등급이 아님. |
| 발견 근거 | 제품 원재료 원문 → 연결된 내 기준 | 추정 매칭이면 추정 이유를 이곳에 표시. |
| 음식에서 하는 일 | CSV의 역할 | 일반적인 용도를 설명하며 특정 제품의 실제 제조 목적을 확정하지 않음. |
| 알아둘 점 | CSV의 쟁점 | 개별 성분이 확인되면 그 성분에 해당하는 내용만 사용. |
| 출처 | 기관·연도 요약과 원문 링크 | 여러 출처는 짧은 요약으로 보이고 펼쳐 원문에 접근. 확인일은 별도 정보. |

**카라기난 예시**

> 카라기난 · 피해요  
> 원재료명에서 ‘카라기난’을 찾았어요.
>
> **음식에서 하는 일**  
> 홍조류 성분으로 걸쭉하게 하거나 젤을 만들어요.
>
> **알아둘 점**  
> 장 염증 관련 연구로 피하기도 해요. 식품용과 분해물을 구분해야 하며 평가에 불확실성이 남았어요.
>
> 출처: [EFSA (2018) · 카라기난 평가](https://www.efsa.europa.eu/en/efsajournal/pub/5238)

‘가능성이 있어요’가 **원료 매칭의 불확실성**을 말한다면 발견 근거에 표시한다. 건강 영향의 가능성을 말하는 문구와 섞지 않는다.

### ② 내 기준 화면: ‘자세히’

1. **음식에서 하는 일**
2. **알아둘 점**
3. **표기 예시**
4. **이 기준으로 찾지 않는 표기** — 한 번 더 접힌 영역
5. **함께 나타나는 기준**

처음에는 별도 용어집 페이지를 만들지 않는다. 결과 화면과 내 기준 화면은 **같은 역할·쟁점 데이터**를 사용하고, 결과 화면에 제품에서 발견한 원문과 매칭 이유를 덧붙인다.

아래 원료·제조 설명은 상세 정보 작성 시 사용하는 참고 열이다. 첫 하단 창에는 짧은 역할·쟁점을 우선 표시하며, 긴 설명이 필요하면 추가로 펼쳐 읽게 한다.

## 원료물질과 묶음 기준의 표시

| 구분 | 예시 | 주의점 |
|---|---|---|
| 기준에서 찾는 물질 | 당알코올 → 에리스리톨·자일리톨·말티톨 등 | 검색 범위의 예시이며 한 제품의 배합표가 아님. |
| 물질의 출발 원료·공정 | 잔탄검 → 당의 미생물 발효, 젤라틴 → 동물 조직의 콜라겐 가공 | 여러 유래가 가능하면 가능한 범위를 설명. |
| 제품에서 확인된 실제 구성 | 혼합제제(카라기난, 덱스트린) → 표시된 두 성분 | 실제 표시된 이름만 함유 목록으로 사용. |
| 제품에서 확인되지 않은 정보 | 레시틴의 유래, 향료의 구성, 쇼트닝의 사용 기름·제조 공정 | ‘표시만으로 확인할 수 없어요’. 일반적인 제조법으로 빈칸을 채우지 않음. |

## 짧은 문구를 해석할 때 필요한 보충 설명

### 가공 유지와 식용유

‘원료에서 기름을 꺼내기’와 ‘기름의 성질 바꾸기’를 구분한다.

| 단계·공정 | 무엇을 하는가 | 혼동하지 않을 점 |
|---|---|---|
| 압착·용매 추출 | 원료에서 기름을 분리 | 용매를 사용했다는 사실과 최종 잔류량은 다른 정보. |
| 정제 | 냄새·색·불순물 등을 조절 | 정제와 경화는 같은 공정이 아님. |
| 분별·배합 | 녹는 성질이 다른 지방을 나누거나 섞음 | 고체 지방이라는 이유만으로 수소첨가를 했다고 볼 수 없음. |
| 부분 수소첨가(부분경화) | 불포화지방의 일부 결합을 바꿔 물성을 조절 | 트랜스지방이 생길 수 있어 규제 대상이 된 공정. |
| 에스테르 교환 | 지방산의 결합 위치·배치를 바꿔 물성을 조절 | 부분경화와 다른 공정. 이 이름만으로 트랜스지방 발생을 단정하지 않음. |

공정 설명 근거: [FAO (1994) · 유지 추출·정제 공정](https://www.fao.org/4/V4700E/V4700E0a.htm) · [WHO (2019) · REPLACE 모듈 2](https://www.who.int/docs/default-source/documents/replace-transfats/replace-module-2-p.pdf) · [FDA · 트랜스지방·부분경화유](https://www.fda.gov/food/food-additives-petitions/trans-fat).

마가린은 보통 지방에 물 등을 섞어 유화하고, 쇼트닝은 주로 지방으로 제과의 바삭함·부드러움과 크림의 형태를 만든다. 제조사는 **원가·일정한 질감·보관성·작업성**을 위해 배합과 가공 방식을 선택할 수 있다. 식물성 위주 제품도 있고 동물성 유지가 쓰이는 경우도 있으므로, 특정 제품의 출발 기름은 배합표로 확인한다. 핵심 설명을 ‘유지의 한 종류’로 축약하지 않는다. [FAO (1994) · 유지의 식품 용도](https://www.fao.org/4/V4700E/V4700E0b.htm) · [WHO (2019) · REPLACE 모듈 2](https://www.who.int/docs/default-source/documents/replace-transfats/replace-module-2-p.pdf).

기름 종류만으로 반복 가열 이력이나 공정 오염물의 양을 알 수 없다. 씨앗기름에 대한 선호는 표시할 수 있지만, 오메가6 함유를 곧 염증·질병의 증거로 바꾸지 않는다. [WHO (2023) · 지방 섭취 지침](https://www.who.int/news/item/17-07-2023-who-updates-guidelines-on-fats-and-carbohydrates) · [EFSA (2018) · 유지의 3-MCPD 평가](https://www.efsa.europa.eu/en/press/news/180110).

### 감미료·식이섬유

난소화성말토덱스트린은 **식이섬유를 보충하면서 부피·질감을 만드는 가공 원료**다. 일반 말토덱스트린과 소화 성질이 다르다. 원료명만으로 완제품의 식이섬유 함량을 추정하지 않는다. [FDA (2018) · 식이섬유 표시 지침](https://www.fda.gov/regulatory-information/search-fda-guidance-documents/guidance-industry-declaration-certain-isolated-or-synthetic-non-digestible-carbohydrates-dietary).

WHO의 2023년 비당류 감미료 지침은 체중조절 목적 사용에 대한 **조건부 권고**다. 기존 당뇨병 환자는 적용 대상에서 제외되며, 당알코올·저열량 당에도 그 권고를 그대로 적용하지 않는다. 개별 물질의 독성 평가나 법적 사용기준을 대신하는 자료가 아니다. [WHO (2023) · 비당류 감미료 지침](https://www.who.int/publications/i/item/9789240073616).

알룰로스·트레할로스의 GRAS 신고 자료를 인용한 부분은 **신청자가 제출한 조성·사용 목적·시험 기록**에 관한 것이다. FDA의 독립적인 안전성 확정이나 허가로 표현하지 않는다. 특히 GRN 912는 신청자 요청으로 FDA 검토가 중단된 기록이며, 여기서는 당의 정체와 용도 설명에만 사용한다. [FDA의 GRN 912 기록](https://hfpappexternal.fda.gov/scripts/fdcc/index.cfm?id=912&set=GrASNotices).

### 첨가물 연구와 묶음 기준

카라기난의 짧은 문구는 **EFSA 2018년 평가**에 근거한다. 분자량·노출·독성 자료의 불확실성과 추가 자료 요청을 설명한 것이며, 식품용 카라기난과 분해물인 폴리기난을 구분한다. 과거의 평가 연도를 최신 확인일로 바꾸거나, 자료 요청을 사용 금지로 표현하지 않는다. [EFSA (2018) · 카라기난 평가](https://www.efsa.europa.eu/en/efsajournal/pub/5238).

CMC 인체시험은 건강한 성인 **16명, 11일, CMC 투여군 하루 15g**이라는 조건에서 장내미생물 등의 변화를 관찰했다. 이 결과를 레시틴·펙틴·모든 검류의 공통 위험으로 옮기지 않는다. 결과에서 실제 성분이 확인되면 그 성분에 맞는 설명을 보여줘야 한다. [Chassaing 등 (2022) · CMC 인체시험](https://pubmed.ncbi.nlm.nih.gov/34774538/).

BHA의 2026-02-10 발표는 재평가 **착수**다. 금지 결정이나 모든 산화방지제의 평가 결과가 아니다. 이산화티타늄에 대한 EFSA의 2021년 평가 역시 해당 물질에 한정한다. [FDA (2026) · BHA 재평가 착수](https://www.fda.gov/news-events/press-announcements/fda-launches-assessment-bha-common-food-chemical-preservative) · [EFSA (2021) · 이산화티타늄 평가](https://www.efsa.europa.eu/en/news/titanium-dioxide-e171-no-longer-considered-safe-when-used-food-additive).

## 저장소와 연결할 때 확인할 사항

| 현재 상태 | 연결 시 처리 |
|---|---|
| 난소화성말토덱스트린에 ‘난소화성전분’도 매칭 | 동의어로 설명하지 않는다. 발견 원료별 설명 또는 규칙 분리가 필요하다. |
| ‘달걀’ 기준에서 메추리알·오리알도 탐지 | 포함 범위를 표기 예시에 밝히고 실제 종을 바꾸어 표시하지 않는다. |
| 갑각류·조개·오징어류에 해삼·성게·멍게도 포함 | 전부 갑각류·연체류라고 설명하지 않는다. |
| 팜유·팜핵유, 참기름·들기름이 각각 한 기준 | 원료와 지방 조성을 개별로 구분한다. |
| 역할별 첨가물 기준에 서로 다른 물질이 포함 | 그룹 쟁점 중 실제 발견 물질에 해당하는 설명만 연결한다. |
| 같은 성분이 둘 이상의 기준에 매칭 | 중복된 위험 개수처럼 보여주지 않고 ‘함께 나타나는 기준’으로 연결한다. |
| 현재 CSV는 기준 ID 단위 | 앱 연결 시 제품별 발견 원문·매칭 확실성은 분석 결과에서 가져온다. 원료·제조 참고 열을 새 제품 정보로 추정하지 않는다. |

지역 기준은 **관할·개별 물질·식품군·시행일·단위**로 비교한다. ‘대륙별 안전/위험’, 자료가 없으니 금지 또는 무제한 허용이라는 추정은 하지 않는다. 이번 CSV는 설명 문구이며 모든 국가의 허용 조건을 담은 규제표가 아니다. 기존 자동 수집 후보는 검토된 근거와 구분한다. [기존 데이터 검증 문서](20_데이터검증_결론과_해소방안_Codex.md)

공정 설명에는 FAO·Codex, 기관 평가에는 WHO·FDA·EFSA 등의 1차 자료를 사용했다. 과거 자료에서는 제조 원리와 해당 연도의 평가만 참고하며 당시 제품 조성·허용 상태를 현재 값처럼 사용하지 않는다.
