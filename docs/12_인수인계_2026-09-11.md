### 1-1. 공공데이터 API 시간 제한 — 임시 조치임 (중요)

**공식 공지 확인:** 식품안전나라 「묻고 답하기」

> [공공데이터 Open-API 제한적 운영 안내] 2026-07-07 ~ 종료일 별도 공지
> - 평일 09~19시 `ERROR-500` 반환. 인증키·URL 문제 아님
> - 사유: 26년 상반기 호출량 급증 → 서버 과부하
> - **정상화 목표: 8월 말~9월 초. 일정 확정 전**
> - CSV 파일 다운로드는 2026-09-04부터 제공

**실측 (정식 키 — `.env.local`의 `FOODSAFETY_API_KEY`):**
```
08:56  INFO-000    정상
09:03  ERROR-503   09시~19시에는 서비스가 제한됩니다
09:14  ERROR-503   (json/xml, User-Agent 무관, 우회 불가)
```
- 응답 코드가 공지의 `ERROR-500`이 아니라 `ERROR-503` — 미묘하게 다름
- `apis.data.go.kr` 채널은 24시간 정상 (수입식품·첨가물 등). 단 C002·C006·C003은 여기 없음

**→ 시간 제한을 영구 제약으로 설계하지 않는다.** 정상화되면 실시간 API 폴백을 되살린다. 단 Supabase 전량 적재는 시간 제한과 무관하게 필요 (제품명 유사도 매칭은 API로 불가).

### 1-4. 내 이전 판단 2개 정정 (실측 기반)

| 항목 | 이전(잘못) | 실측 정정 |
|---|---|---|
| **원재료 누락** | "결번 = 누락, UI에 표시 필요" | ❌ **아니다. ORDNO 개수 == 원재료 개수 98.6%.** 실제 누락 1.4%뿐 |
| **RAWMTRL_ORDNO** | "뒤섞여 무의미 → 버린다" | ✅ **순서 복원 키다. 49.9%가 역순 저장(`7,6,5,4,3,2,1`). 반드시 유지.** ORDNO로 정렬하면 원래 표시 순서 복원 → **공공DB로도 함량 정도 판정 가능** |

**→ "라벨 원문 1차, 공공DB 보조" 구조 역전을 재검토해야 한다.** ORDNO 정렬로 공공DB에서도 함량 순서를 얻을 수 있으므로, 공공DB가 다시 강력한 1차 경로가 될 수 있다.

### 2-1. `10_데이터_인벤토리.md` — 전수 조사

**핵심 발견:**
- 식품안전나라 API **178건** 전수 열람. 제품·원재료·안전·인증 데이터 상세 인벤토리
- **`15127578` 식품영양성분DB** — `ITEM_REPORT_NO`로 C002와 조인. `AMT_NUM6~8`(탄수·당류·식이섬유), `AMT_NUM53/55/56`(당알콜·알룰로오스·에리스리톨) → **순탄수 자동계산 가능**. "통합 자료집" 파일도 제공
- **`15143798` 푸드QR** — 11개 API 중 **알레르기 구조화 정보** 유일 후보. 바코드+보고번호 함께 제공 가능. 단 실키 검증 필수
- **`I0950` 식품첨가물공전 6,895건** — 성분 카드 ①계층(용도·기준) 출처. 단 "제품에 들어간 첨가물 DB"가 아니라 공전/기준
- **`15098434` 수입식품 제품 목록** — 연도별 CSV 직접 다운로드 (2019~2025)

**아키텍처 제약 5가지 (Codex 결론):**
1. C002 원재료는 쉼표 문자열, 원재료 코드 없음 → 표준 마스터와 확정 FK 없음
2. C002/I1250은 **2017년 이후 내수·겸용** 범위. "전 제품/전 기간" 아님
3. 바코드 C005는 **2018년 이후 갱신 중단**. 신뢰도/최종확인일 필요
4. 알레르기 구조화 데이터는 품목제조보고에 없음. FoodQR 검증 전 의존 불가
5. 대량 초기 적재는 **파일 다운로드 우선**. 파일도 1일 10회 제한

### 2-2. `11_V6_유사앱_조사.md` — 🔴 계획서 핵심 가정 뒤집힘

**"유사 앱 7개 전멸"은 사실이 아니었다:**
- 해외 앱 3개(케토스캐너·Keeto·Chomp) — **한국 시장에 온 적 없음**
- 국내 앱 4개 — **출시 11일~5개월**. 실패 판정할 수 있는 앱이 없음
- 세이프리스트·Chomp가 "개인 기준 설계 시도, 평가 0" → 세이프리스트는 출시 11일, Chomp는 한국 미진입
- **평가 수 0~5는 실패가 아니라 나이의 증거**

**진짜 선례 = 엄선 (2016~2025, 폐업):**
- 사용자 50만, 주3회 방문 65%, 투자 20억 → **수요·유통은 증명됨**
- **소비자 과금 흔적 없음.** 돈을 식품기업(평가단·시식·브랜드 AI)에서 찾다가 정체성 잃고 폐업
- 생존한 유사 서비스(화해·맘가이드·인아웃)는 **전부 판매자/브랜드에서 돈을 번다**

> **🔴 계획서의 "무료로 모은 뒤 유료화"는 엄선이 걸어간 길이다.**
> B2C 과금은 "우리는 판단하지 않는다" 원칙과 맞는 유일한 수익 경로인데, **가장 검증 안 된 경로다.**

**새 가설 ⑤ 수익 구조** — 전멸 가설 표에 추가 필요.

**G0 게이트 재정의 필요:** "①②④ 중 하나" 조건은 조사 결과와 안 맞음. → 예: "G4(본인 2주 사용) 이후 베타에서 지불의사 신호 X 이상"

**V6에서 남은 사용자 작업 (§5):**
1. 국내 앱 4개 설치·테스트 (언라벨·CheckEat·키토메이트·세이프리스트 + Aindly) — 3h
2. 언라벨 유료 구독 가격/조건 확인
3. Google Play 설치 수 확인
