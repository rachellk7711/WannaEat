## 1. 제품 개요

**내가 먼저 정한 피해요·알려만줘요 기준에 비춰, 가공식품의 원재료 표시를 읽어 대조해 주는 웹 도구입니다.**

제품은 제품을 평가하지 않습니다. 사용자가 정한 기준과 라벨에 적힌 내용을 대조한 결과만 보여줍니다.

## 2. 대상 사용자와 문제

- **대상:** 저탄고지·카니보어 식단을 실천하는 성인 (1차 버전)
- **문제:** 회원 30만 명 규모의 국내 최대 키토 카페에는 「성분 질문게시판」이 따로 있고, 공지는 "성분표 첨부 필수"입니다. 사용자들은 제품 사진을 올려 다른 사람에게 성분 판단을 물어봅니다.
- **현재 대안의 한계:** 커뮤니티 질문은 답이 늦고 사람마다 다릅니다. AI 챗봇은 같은 질문에도 답이 달라집니다. 기존 앱은 모든 사용자에게 같은 점수를 주므로 개인 기준이 있는 사람에게는 쓸모가 적습니다.
- **우리의 접근:** 판단 기준을 사용자에게 두고, 대조는 **고정된 규칙**으로 수행해 **언제 물어도 같은 답**을 냅니다.

## 3. 범위

| 포함 | 제외 (1차 버전) |
|---|---|
| 원재료명이 표시된 가공식품 | 자연식품 원물 (원재료 표시가 없음) |
| 저탄고지·카니보어 모드 | 알레르기·비건·영유아·종교 식단 모드 |
| 라벨 이미지 분석 | 장바구니 화면 일괄 확인 |
| 제품명으로 공공DB 조회 | 순탄수·순단백질 정량 계산 |
| 분석 이력과 재구매 목록 | 레시피 추천 |

> 알레르기 모드는 오류 시 사용자 피해가 크므로 1차 버전에서 의도적으로 제외했습니다.

## 4. 핵심 사용자 흐름

```
1. 가입·로그인
2. 내 기준 설정        성분별 2단계 — 피해요 / 알려만줘요
                       각 성분에 판단 근거(용도·각국 기준·출처)를 함께 제공
3. 제품 입력           라벨 촬영·캡처 업로드  (또는 제품명 입력)
4. 전송 전 확인        올릴 영역을 확인. 필요하면 잘라내기
5. 원재료 추출         이미지에서 원재료 표시를 글자로 읽음
6. 기준 대조           내 기준과 대조한 결과 + 판독 상태
7. 이력 저장           분석한 제품이 자동으로 쌓임 → "내 기준 통과 목록"
```

2번과 6번이 제품의 본체입니다.

**기준 설정 표기 (2026-09-18 사용자 결정)**

| 설정 | 의미 | 발견했을 때 |
|---|---|---|
| **피해요** | 이 원재료가 표시된 제품을 피하고 싶어요. | 표시 위치와 관계없이 기준 불일치에 포함 |
| **알려만줘요** | 이 원재료가 표시되면 알려주세요. | 발견 사실을 안내하되 기준 불일치에 포함하지 않음 |

표시 위치는 참고 정보이며, 양이나 허용 여부의 판단 기준으로 쓰지 않습니다. 선택하지 않은 원재료는 개인 기준 대조 대상에서 제외하며 세 번째 설정으로 표시하지 않습니다. 확인 불가와 판독 실패는 두 설정 모두 별도 안내합니다.

## 5. 기능 요구사항

| 기능 | 설명 | 우선순위 |
|---|---|---|
| 기준 설정 | 성분별 피해요/알려만줘요 2단계 설정. 모드 기본값을 제공하되 사용자가 확인·수정해 확정 | Must |
| 성분 근거 카드 | 성분마다 원료·용도와 각국 기준을 출처와 함께 2~3줄로 제공, 상세는 접어둠 | Must |
| 이미지 입력 | 갤러리 선택·카메라 촬영. 전송 전 확인 화면 필수 | Must |
| 원재료 추출 | 표시 순서를 그대로 보존해 텍스트로 추출 | Must |
| 기준 대조 | 고정 규칙으로 대조. 같은 입력이면 항상 같은 결과 | Must |
| 판독 상태 표시 | 확인 불가 성분·판독 실패를 결과와 분리해 표시 | Must |
| 분석 이력 | 자동 저장. 당시 기준을 함께 보존하고, 기준이 바뀌면 재대조 제공 | Must |
| 제품명 조회 | 라벨이 없을 때 제품명으로 공공DB 조회 | Should |
| 내 기준 통과 목록 | 이력에서 필터링한 재구매 목록 | Should |
| 텍스트 직접 입력 | 위 경로가 모두 실패할 때 | Should |
| 장바구니 일괄 확인 | 여러 제품을 한 번에 | Later |
| 순탄수 계산 | 제품별 영양성분 기반 | Later |

## 6. 결과 표현 규칙 (제품의 핵심)

원재료명은 법적으로 **많이 사용한 순서**로 표시합니다. 따라서 **표시 위치**로 상대적인 비중을 짐작할 수 있습니다. 다만 **함량 자체를 알 수는 없습니다.**

- 중량 2% 미만 원재료는 순서를 따르지 않아도 됩니다.
- 중량 5% 미만 복합원재료는 하위 원료를 밝히지 않아도 됩니다.

따라서 **위치는 성분의 속성으로만 쓰고, 함량으로 말하지 않습니다.**

**① 제품 단위 — 결론 한 줄**

| 결과 | 의미 |
|---|---|
| **기준 불일치 · N개** | 회원님이 피해요로 설정한 성분이 발견됨 |
| **기준 내** | 피해요로 설정한 성분이 발견되지 않음. 알려만줘요 항목의 발견 사실은 별도 안내 |
| **판단 보류** | 읽지 못한 부분이 있어 결론을 낼 수 없음 |

**② 성분 단위 — 무엇이 어디에**

```
설탕      원재료 앞쪽 표시     피해요 → 불일치
밀가루    원재료 중간 표시     피해요 → 불일치
정제소금  원재료 뒤쪽 표시     알려만줘요 → 발견 사실 안내 (불일치에 포함하지 않음)
```

**③ 판독 상태 — 항상 별도 줄로 함께 표시**

`기준 내`로 끝나더라도 확인 불가가 있으면 반드시 병기합니다. 라벨에 적히지 않은 것을 보증할 수는 없기 때문입니다.

```
내 기준 대조   피해요로 설정한 성분 발견되지 않음
판독 상태      ⚠ 확인 불가 3개 — 복합조미식품, 혼합제제, 기타가공품
               하위 원료가 라벨에 표시되지 않아 내용을 알 수 없습니다
```

국내 가공식품 표본(30만 건)의 **34%가 하위 원료를 밝히지 않은 복합원재료를 포함**합니다. 이는 라벨 제도의 한계이며, 숨기지 않고 그대로 알립니다.

**금지 표현:** 제품 등급·점수·순위, "안전·위험·추천·부적합", 건강 영향 서술. 색상은 강도만 나타내며 신호등처럼 쓰지 않습니다.

## 7. 품질 기준

| 지표 | 목표 |
|---|---|
| **거짓 안심** — 제한 성분이 있는데 "발견되지 않음"으로 표시 | **0건** (실물 라벨 20장 검사) |
| 판단 보류 비율 | 측정해 기록. 과도하면 사전을 보강 |
| 결과까지 걸린 시간·수정 횟수 | 측정해 기록 |
| 동일 입력 재현성 | 항상 동일 결과 |

## 8. 비용과 사용 한도

**무료 서비스입니다. 요금을 받지 않고, 구독·인앱 결제·광고를 넣지 않습니다** (2026-09-18 결정).
운영자가 사업자가 아니어서 앱인토스에서 유료 상품을 팔 수 없습니다.

| 항목 | 내용 |
|---|---|
| 상한 | **월 2만원.** 사진 읽기 비용이 이 금액에 닿으면 기능을 닫고 다시 준비합니다 |
| 사용 한도 | 기기당 하루 10장. 남은 횟수를 화면에 표시합니다 |
| 원가 | 사진 한 장 약 0.56원 (2026-09-18 실측) |
| 받지 않는 것 | 가격·결제 수단·카드 정보. 브랜드 광고·제휴 커머스도 받지 않습니다 — 성분 정보의 중립성과 충돌하기 때문입니다 |

## 9. 일정과 확인 지점

각 지점의 조건을 통과하지 못하면 다음 단계로 넘어가지 않습니다.

| 단계 | 기간 | 통과 조건 |
|---|---|---|
| 1차 버전 개발 | 11~13주 (주 20시간 기준) | 촬영 → 원재료 추출 → 기준 대조가 끝까지 동작 |
| 판독 품질 점검 | 개발 중 | 제한 성분을 놓친 건수 **0건** (7. 품질 기준) |
| 자가 검증 | 개발 직후 | 개발자 본인이 2주간 실제 장보기에 사용해 쓸 만한가 |
| 공개 출시 | 상시 | 별도 베타를 두지 않고 바로 공개합니다 (2026-09-18 결정). 위험은 사용 한도와 월 예산 상한으로 관리합니다 |
| 운영 | 상시 | 월 비용이 상한(2만원) 안에 머무는지 |

> 각 조건의 목표 수치는 해당 단계를 시작하기 전에 정합니다.

## 10. 가정과 한계

1. 표시 순서는 사용량 순이 원칙이지만 2%·복합원재료 예외가 있습니다. 위치는 참고 정보이며 함량이 아닙니다.
2. 제품의 34%는 확인할 수 없는 복합원재료를 포함합니다.
3. 이미지 판독은 완전하지 않습니다. 최종 확인은 제품 실물 표시로 해야 합니다.
4. 즉석판매제조가공품(빵집·반찬가게)은 공공DB에 없습니다. 라벨이 있으면 촬영으로 처리합니다.
5. 본 서비스는 제품의 안전성·품질을 평가하지 않으며, 의학적 조언을 제공하지 않습니다.
