# 검증보고서(`13`) 대응 기록

작성일: 2026-09-14 · 대상: `docs/13_계획서_검증보고서.md`

> 보고서는 **중간본(약 1,560줄)** 을 기준으로 작성됐다(인용 줄 번호로 확인). 그 사이 이미 반영된 항목(C006 ORDNO 검증, "49.9%" 삭제, 입력 경로 표)은 판단에서 제외했다.

## 직접 재확인한 사실

| 주장 | 확인 |
|---|---|
| 바코드 기본키 충돌 | ✅ 259,669행 / 고유 229,040 / 2개 이상 품목번호에 연결된 바코드 13,740 — 보고서 수치와 일치 |
| 중복 제거가 첫 행만 남김 | ✅ `02_prepare_csv.py` 45~54행 — 내용·변경일 비교 없음 |
| RLS·`strength` 제약 없음 | ✅ `01_schema.sql`에 둘 다 없음 |
| 3a~3e 합계 | ✅ 20+6+10+30+24 = **90h** (계획서는 74h로 적혀 있었음) |
| 표시 순서 ≠ 함량 | ✅ **표시기준: 2% 미만은 순서 예외, 5% 미만 복합원재료는 하위 원료 생략 가능** — 보고서보다 강한 근거 |

**추가로 실측한 것:** C002 30만 건 표본에서 **34.0%가 하위 원료를 밝히지 않은 복합원재료 포함**(복합조미식품 21%, 기타가공품 13.6%, 혼합제제 11%). 보고서가 제기한 "복합원재료 처리" 문제의 규모를 수치로 확인했다.

## 수용 (14건)

| 지적 | 반영 |
|---|---|
| 결과는 함량이 아니라 표시 근거 | 결과 라벨을 **앞쪽/중간/뒤쪽 표시 · 발견되지 않음 · 판단 보류**로 교체. "함량 정도"라는 말을 문서 전체에서 제거 |
| 기준 설정 완료 상태·버전, 과거 결과 스냅샷 | 사용자 검토 체크리스트 4·6번, `analysis_history` 계약 |
| 판독 완전성과 판정 분리 | **판정과 판독 상태를 항상 함께 표시**하는 규칙 신설 (계획서·PRD·`02` §4-2-1) |
| ORDNO는 "정렬 후보 키" | 표현 완화. 실물 대조는 G3로 명시 |
| 라벨과 DB의 출처·시점 분리 | **라벨 우선, DB 보조**로 1차 경로 확정. 충돌 시 차이 표시, 공공 마스터 미갱신 |
| 성분 카드에 기준 종류·단위·조건 | MSG 예시를 "사용기준 / 섭취허용량"으로 구분해 수정. "원료는 기준 개념 없음" 완화 |
| 거짓 안심 건수를 지표로 | G3 통과 조건을 **거짓 안심 0건**으로 교체 |
| 베타 3질문·사전 기준치 | G5 재정의, `06` 명세에 반영 |
| 3a~3e 90h | 시간표 재작성 (총 177h) |
| "베타 고정비 0원" 폐기 | Gemini 유료 티어 확정, 호스팅 교체로 재산정 |
| 핵심 흐름을 전체 적재보다 먼저 | 실행 순서 재배열 — 1단계 제품 규칙 → 2단계 핵심 흐름 → 3단계 적재 |
| 업로드 크기 제한 | 클라이언트 압축·전송 본문 실측을 `03` 명세와 실측 항목에 추가 |
| Gemini 18세 조건 | 이용약관·베타 모집 대상에 반영 |
| 사업자등록 기준 | "매출 후" → **사업 개시일 기준, 유료 전환일 전 완료** |

## 부분 수용 (4건)

| 지적 | 우리 판단 |
|---|---|
| 크롭 강제는 법적 필수가 아님 | 동의. 단 **전송 전 확인 화면은 건너뛸 수 없게 유지**하고 크롭만 선택으로 바꿨다. "법적 필수" → "보호 장치"로 재분류 |
| 신호등 색 금지는 법 조항이 아님 | 동의. **디자인 원칙**으로 재분류하되 원칙 자체는 유지 |
| 근거자료집을 선행조건 삼지 말 것 | 동의. **베타 전에는 식품원료 + 감미료까지만** |
| 바코드 다대다 모델 | **MVP에서 C005 적재 자체를 보류**하는 쪽이 더 단순하다 — 바코드 입력 기능이 없고 2018년 이후 갱신이 끊겼다 |

## 거절 (1건)

| 지적 | 거절 사유 |
|---|---|
| **유료 전환일 사전 고지는 "별도 보류"** | 수익화 설계의 **중심으로 채택**했다. ① V6 ⑤(엄선: 무료로 모으고 끝내 과금하지 못함)에 가장 직접적인 대응이다 — 날짜가 B2C 과금을 강제한다. ② 설문·알림 신청은 결제의 증명이 아니지만(보고서도 인정), **전환일의 실제 결제율은 진짜 지불의사 데이터**다. ③ 카드 미등록 + 사용자 직접 신청 구조라 개정 전자상거래법의 자동 전환 규제와도 맞는다. 보고서의 가상 가격 시험은 **전환일 전 측정 단계**로 흡수했다 |
