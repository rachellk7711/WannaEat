# 알고먹을래? · WannaEat

사용자가 고른 기준으로 가공식품의 원재료 표시를 확인하는 앱인토스 서비스.

- `apps/wannaeat/`: React·TypeScript 기반 앱인토스 WebView 앱
- `docs/`, `계획서(토스).md`: 서비스 설계와 데이터 검토 문서
- `scripts/`: 원재료 데이터 수집·정리·검토 도구. 과거 스키마 초안도 포함되어 있으므로 전체 스크립트를 일괄 실행하지 않는다.
- `data/`: 로컬 원본·정리 데이터. 대용량 자료와 작업 중인 데이터는 Git에서 제외한다.

## 로컬 실행

Node.js 24 이상에서:

```sh
cd apps/wannaeat
npm ci
npm run dev
```

앱에 카탈로그 스냅샷이 포함되어 있어 Supabase 키 없이도 기준 선택·기기 내 저장이 가능하다.
실제 Supabase 연결과 카탈로그 갱신 방법은 [앱 README](apps/wannaeat/README.md)를 참고한다.

## 현재 범위

녹색 A안, 분류 → 소분류 → 기준 선택, 동의 표기 검색, 피해요/알려만줘요 설정,
Supabase Storage의 공개 카탈로그 읽기, 기기 내 사용자 기준 저장, 사진 미리보기를 구현했다.

OCR·실제 원재료 판정·토스 로그인·사용자 기준의 서버 동기화는 아직 구현하지 않았다.
카탈로그의 검색어는 선택 화면을 위한 자료이며 판정 규칙으로 사용하지 않는다.
